Contexto do produto

O que é o Ticket Moove

Plataforma SaaS para gestão de inscrições em eventos esportivos de endurance: corridas de rua, triathlon e ciclismo. Posicionada como parceiro do organizador — não apenas uma ferramenta. Menor taxa do mercado, repasse rápido, atendimento próximo e ferramentas de captação de atletas.

🏃 Quem usa
Dois perfis distintos com necessidades bem diferentes.
  • Organizador de evento — usa o painel admin para criar eventos, gerenciar inscrições e acompanhar resultados
  • Atleta — acessa a página pública do evento para se inscrever, recebe confirmação por e-mail com QR code
🎯 Posicionamento visual
A marca precisa transmitir os pilares do produto.
  • Confiança — dinheiro do organizador precisa estar seguro
  • Energia — contexto esportivo, movimento, performance
  • Parceria — próximo, humano, não genérico
  • Clareza — telas limpas, dados visíveis, zero ruído
Identidade de marca

Nome e personalidade

O nome Ticket Moove une dois mundos: "Ticket" remete ao produto (inscrição, ingresso, acesso) e "Moove" ao movimento — endurance, performance, estar em ação. O duplo "o" é intencional, cria distinção visual e memorabilidade.

⚡
A logo precisa funcionar em fundo claro, fundo escuro e em tamanho pequeno (favicon, app icon). Testar em contextos reais: cabeçalho de e-mail, crachá de evento, camiseta de organizador.

Paleta de cores

🎨
As cores serão definidas pela equipe de design junto com a criação da logo e identidade visual. O que o produto precisa que a paleta transmita: confiança (organizador deposita dinheiro na plataforma), energia (contexto esportivo, movimento, endurance) e clareza (interface de dados limpa). A paleta deve funcionar tanto no painel admin (produto B2B, mais sóbrio) quanto na página pública do evento (B2C, mais impacto).

Página pública do evento
Quem vê: atletas, público geral
Público

Elementos obrigatórios

  • Hero com banner do evento — imagem ou gradiente de marca do organizador. Título grande, data, local
  • Informações do evento — data completa, horário, endereço com link para mapa, capacidade e vagas restantes
  • Descrição do evento — texto do organizador sobre percurso, categorias, kits, etc.
  • Lotes / preços — exibir lote ativo com preço em destaque. Mostrar lotes futuros como "em breve"
  • Formulário de inscrição inline na mesma página (não redireciona). Nome, e-mail, CPF, telefone, data de nascimento + campos customizados do organizador
  • Botão CTA principal — "Quero me inscrever" / "Confirmar inscrição"
  • Rodapé mínimo — "Powered by Ticket Moove" com link

Estados da tela

  • Inscrições abertas — formulário visível, CTA ativo
  • Esgotado — "Vagas encerradas" — sem formulário, opção de lista de espera (futuro)
  • Encerrado — evento já aconteceu — banner informativo
  • Sucesso — após envio: tela de confirmação com nome do atleta, resumo da inscrição e instrução de verificar e-mail

Comportamentos mobile

  • Hero compacto no mobile — sem cortar informação importante
  • Formulário em coluna única no mobile
  • Teclado numérico no CPF e telefone
  • Botão fixo no bottom no mobile quando o formulário estiver fora da tela
E-mail transacional
Confirmação de inscrição
Quem recebe: atleta inscrito
Público

Elementos obrigatórios

  • Logo da plataforma no topo do e-mail
  • Saudação personalizada — "Boa, [Nome]! Sua inscrição está confirmada."
  • Resumo da inscrição — evento, data, local, lote, valor
  • QR Code de check-in — gerado no momento do envio, único por inscrição
  • Número da inscrição em destaque (ex: #INS-0042)
  • Instruções — "Apresente este QR code no dia do evento"
  • Rodapé — contato do organizador, "Powered by Ticket Moove"
💡
O e-mail precisa ter boa renderização em Gmail, Outlook e Apple Mail. HTML simples, sem CSS externo. QR code como imagem inline (base64).
Telas do admin — painel do organizador

Jornada do organizador

O organizador acessa o painel via app.ticketmoove.com.br. Interface densa mas organizada — ele precisa de dados na cara dura, sem precisar clicar muito. Desktop-first, com responsividade mínima para tablet.

🖥️
Layout global do admin: sidebar fixa à esquerda com logo, navegação e logout. Conteúdo principal na direita. Sidebar colapsável no tablet. No mobile: menu hambúrguer. Fundo: cinza-claro (#F8FAFC), cards brancos com sombra leve.

Componentes do design system

Biblioteca de componentes

Estes são os blocos de construção que precisam estar definidos antes de montar qualquer tela. O design system será implementado em código (React + Tailwind) com base nos tokens entregues.

🔘 Botões
  • Primary — ação principal (azul)
  • Accent — CTA público / atleta (laranja)
  • Secondary — ação secundária (cinza)
  • Outline — ação terciária (borda)
  • Ghost — ação suave (sem fundo)
  • Destructive — ação destrutiva (vermelho)
  • Tamanhos: SM · MD · LG · Icon
  • Estado: default · hover · active · disabled · loading
📝 Inputs e formulários
  • Input text — estados: default, focus, error, disabled
  • Select — dropdown nativo estilizado
  • Textarea — para descrições
  • Label — acima do campo, obrigatório marcado com *
  • Mensagem de erro — abaixo do campo, em vermelho
  • Hint text — instrução abaixo do campo, em cinza
  • File upload — zona de drag & drop para banner do evento
🏷️ Badges e status
  • Rascunho — cinza
  • Publicado — verde
  • Encerrado — azul
  • Cancelado — vermelho
  • Pendente — amarelo
  • Check-in ✓ — azul índigo
📊 Cards e dados
  • Metric card — ícone + label + valor em destaque
  • Event card — para listagens compactas
  • Empty state — ilustração + texto + CTA
  • Skeleton loader — placeholder animado
  • Table — header, linhas, hover, paginação
  • Progress bar — ocupação de vagas
🔔 Feedback
  • Toast — notificação temporária (sucesso, erro, info)
  • Alert inline — aviso dentro de um formulário
  • Modal de confirmação — ações destrutivas (cancelar evento, etc.)
  • Loading spinner — para ações assíncronas
🧭 Navegação
  • Sidebar admin — logo, nav items, avatar/logout
  • Nav item — ícone + label, estados: default, active, hover
  • Breadcrumb — ex: Eventos / Corrida das Pedras
  • Tabs — para filtros dentro de uma tela
  • Dropdown menu — ações "· · ·" por linha de tabela

Entregáveis esperados

O que a equipe de design precisa entregar

🎨 Identidade de marca
  • Logo principal (fundo claro + fundo escuro)
  • Versão horizontal + versão ícone/símbolo
  • Favicon (32×32, 64×64)
  • Paleta de cores oficial com códigos hex
  • Tipografia definida (fontes e hierarquia)
  • Guia de uso da marca (o que pode e o que não pode)
🖼️ Telas — Figma
  • Arquivo Figma organizado por fluxo
  • Componentes no Figma alinhados ao design system
  • Todas as telas P1 em versão desktop
  • Página pública + e-mail em versão mobile
  • Estados de tela (vazio, loading, erro, sucesso)
  • Protótipo navegável para validação com o time
🔤 Tokens de design
  • Cores nomeadas e exportáveis (ex: via tokens JSON ou CSS vars)
  • Escala tipográfica completa
  • Espaçamentos (spacing scale)
  • Border radius por nível
  • Sombras (shadow scale)
📦 Assets para desenvolvimento
  • Ícones em SVG (ou biblioteca definida — ex: Lucide)
  • Imagens de placeholder para eventos
  • Ilustração para empty states
  • Templates de banner de evento (Canva ou Figma) para organizadores usarem
🤝
Alinhamento técnico: O código usa React + Tailwind CSS. Os tokens de cor e tipografia do design serão implementados diretamente como variáveis CSS no projeto. Quanto mais o Figma usar variáveis/tokens, mais fácil e fiel será a implementação.
Referências visuais

Direção estética

O design deve equilibrar o profissionalismo de um produto B2B (painel admin limpo, dados densos) com a energia de uma marca esportiva (página pública com impacto visual). Não precisa ser nenhuma das referências abaixo — serve para alinhar direção.

🏁 Admin: Linear
Interface limpa, tipografia forte, dados densos sem peso visual. Dark sidebar ou light sidebar — os dois funcionam.
🏆 Público: Ticket Sports
Página de evento com hero de impacto, informações do percurso, formulário de inscrição integrado. Referência direta de concorrente.
⚡ Energia: Strava
Tom esportivo sem ser agressivo. Dados de performance com design acessível. Comunidade de atletas — referência de linguagem visual do nicho.
