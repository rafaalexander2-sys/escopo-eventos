# Assets — Logo Ticket Moove

Coloque os arquivos da logo **aqui dentro desta pasta**, com estes nomes exatos:

| Arquivo | O que é | Onde aparece |
|---|---|---|
| `logo.svg` | Lockup horizontal: monograma **TM** + wordmark **ticket moove** | nav, login, onboarding, sidebars, rodapé |
| `logo-mark.svg` | Só o monograma **TM** (quadrado) | favicon / usos compactos |

## Importante (tema escuro)

O `demo.html` tem fundo **preto (#0A0A0A)**. A logo precisa ser a **versão clara/branca**
(TM e wordmark em branco, com os detalhes em lima `#CCFF00`). Uma logo toda preta
**não aparece** no fundo escuro.

- Formato ideal: **SVG** (vetorial, escala perfeita). PNG com fundo transparente também serve.
- Se mandar PNG em vez de SVG, renomeie para `logo.png` / `logo-mark.png` e me avise —
  eu troco a referência no HTML.

Enquanto o arquivo não estiver aqui, o demo mostra um texto provisório "ticket **moove**"
no lugar da logo (fallback automático).
